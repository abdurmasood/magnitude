# Magnitude CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@magnitudeai/cli`, whose `magnitude init` copies the bundled skills into the right folders for any mix of Claude Code, Cursor and Codex.

**Architecture:** A pure planning core (`plan.ts`) turns answers plus a snapshot of what's on disk into an exact list of writes, conflicts and warnings. Thin edges around it read the disk (`skills.ts`, `detect.ts`), ask questions (`prompts.ts`), parse flags (`flags.ts`) and write (`write.ts`). `init.ts` wires them together and is tested end to end in temp directories.

**Tech Stack:** TypeScript (ESM), Node 20+, `@clack/prompts`, `yaml`, `tsup`, `vitest`.

**Spec:** `docs/specs/2026-10-19-cli-design.md`. Read it first; this plan argues from it.

## Global Constraints

- Package name `@magnitudeai/cli`, version `0.1.0`, `bin: { "magnitude": "dist/cli.js" }`, `files: ["dist", "skills"]`, `engines.node: ">=20"`, `"type": "module"`.
- Runtime dependencies: `@clack/prompts` and `yaml` only. Dev: `typescript`, `tsup`, `vitest`, `@types/node`. Install current versions.
- Never write to a `.cursor/` folder.
- Nothing is written before the user confirms, except with `--yes`.
- Paths inside a `FileMap` use `/` separators on every OS.
- Tests never touch the real home folder or the network: every test passes its own temp `home` and `cwd`.
- Commit after each task, conventional format: `<type>(cli): <description>`.

## Review Focus

1. **Running outside a git repo:** the project root falls back to the current directory. Test in Task 4.
2. **Global install on a fresh machine:** `~/.claude/skills` or `~/.agents/skills` doesn't exist yet, so it must be created, not error. Test in Task 5.
3. **A bundled skill with missing or broken frontmatter:** fail fast, naming the skill folder, instead of installing half a set. Test in Task 1.
4. **Running init twice in a row:** everything is identical, so print "Everything is already up to date", write nothing, and skip the confirm. Test in Task 7.
5. **Messy `--skills` / `--agents` values** like `"calibrate, open-pr"` or a repeated name: trim and de-duplicate. Test in Task 6.

## Shared types — `src/types.ts` (created in Task 1, used everywhere)

```ts
export type AgentId = "claude" | "cursor" | "codex";
export type Scope = "project" | "global";
export type FolderKey = ".claude/skills" | ".agents/skills" | ".cursor/skills";
export type FileMap = Record<string, string>; // posix relative path -> utf8 content

export interface Skill { name: string; description: string; manualOnly: boolean; files: FileMap }
export interface Answers { agents: AgentId[]; scope: Scope; skills: string[] }
export interface Roots { project: string; home: string }
/** absolute folder path -> skill name -> its files */
export type Scan = Record<string, Record<string, FileMap>>;

export type WriteStatus = "new" | "identical" | "conflict";
export interface SkillWrite { skill: string; folder: string; dest: string; files: FileMap; status: WriteStatus; readers: AgentId[] }
export interface DuplicateWarning { skill: string; folder: string; agents: AgentId[] }
export interface Plan { writes: SkillWrite[]; warnings: DuplicateWarning[] }
export type Decision = "replace" | "keep";
export interface FinalWrite { dest: string; files: FileMap; mode: "create" | "replace" }
```

### Task 7: `runInit`, prompts and the CLI entry

**Files:** Create `src/prompts.ts`, `src/init.ts`, `src/cli.ts`. Test: `test/init.test.ts`.

**Interfaces:**
- Consumes: everything above
- Produces:
  - `interface InitOptions { argv: string[]; cwd: string; home: string; skillsDir: string; interactive: boolean; log: (line: string) => void }`
  - `runInit(opts: InitOptions): Promise<number>` — the exit code
  - `prompts.ts`: `askAnswers(defaults: Answers, preset: Partial<Answers>, skills: Skill[]): Promise<Answers | null>`, `askDecisions(conflicts: SkillWrite[]): Promise<Record<string, Decision> | null>`, `askConfirm(lines: string[]): Promise<boolean | null>`. `null` means cancelled.

**Flow in `runInit`:** parse flags → if not interactive and no `--yes`, print `Not a terminal. Re-run with --yes (and --agents) to install without questions.` and return 1 → root, detect, load skills → answers (prompts or `resolveNonInteractive`) → scan the target folders plus every folder in `foldersReadBy` → `buildPlan` → print warnings → decisions (prompts, or `replace`/`keep` from flags; default keep) → `resolveWrites` → if empty, print `Everything is already up to date.` and return 0 → review + confirm (skipped with `--yes`, but review lines are still printed) → `applyWrites` → next-step lines → 0. Cancel at any prompt: print `Cancelled. Nothing was written.` and return 1. `UsageError`: print its message and return 2.

`cli.ts`: `process.exitCode = await runInit({ argv: process.argv.slice(2), cwd: process.cwd(), home: os.homedir(), skillsDir: bundledSkillsDir(), interactive: process.stdin.isTTY === true, log: console.log })`. `--version` prints `version` read from `package.json`.
